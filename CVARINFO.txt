// ============================================================================
// EVERY SETTING, AND WHICH ONES THE RENDERER READS.
//
// Two kinds, and they behave differently:
//
//   PLACEMENT SETS -- <prefix>_ofs_x/_y/_z, _yaw/_pitch/_roll, _scale and
//   _scale_x/_y/_z. The RENDERER looks these up by name on every frame it draws,
//   which is the only reason a slider moves the thing while the menu is open
//   and you are looking at it. A prefix is live when a MODELDEF PlacementCVars
//   or an actor's PlacementPrefix names it. Sizes must be above zero: the
//   renderer ignores a zero or negative _scale, so those sliders start at 0.05.
//
//   Everything else is read by the playsim every tic.
//
// NEW NAMES WHERE THE MEANING CHANGED, ON PURPOSE. A cvar already saved in
// doomxr.ini outranks any default changed here, forever. wm_grab_radius=6,
// wm_insert_radius=6 and wm_letgo_radius=11 are saved there and would have
// overridden every card's own reach and the new well no matter what this file
// said. So those settings have new names -- and the m4a3 seat you tuned
// (wm_prop: forward 28.5, up 6.75, yaw -90) is carried INTO wm_main's defaults
// rather than lost. The hand seats are per kind of gun (wm_hs_*): their section
// says where each one started.
//
// tools/menu_lint.py checks this file against MENUDEF and the ZScript on every
// build: a slider for a cvar nothing reads, or a read of a cvar nothing
// declares, fails the build before it ever reaches a headset.
// ============================================================================

// ---- YOUR HAND ON EACH KIND OF GUN (renderer) -------------------------------
//
// wm_hs_<profile>_<main|off>_<seat>: a set PER KIND OF GUN, not per hand. They were
// per hand once -- wm_main_slide and the rest, shared by every gun -- and the
// revolver's tuning moved the pistol's hand. zscript/wm/handprofile.zs picks the set:
// the card's handprofile, its type, or the uncalibrated seats (default).
//
//   profile  default pistol shotgun breakaction revolver rifle smg chaingun plasma
//            launcher bfg railgun flamethrower chainsaw -- or a weapon package's own
//   main|off the GUN's hand: _main_ is a hand on the gun in your main hand (your off hand)
//   seat     slide (a slide, charging handle, bolt, hammer) | mag (pushing a magazine
//            home) | support (bracing) | forend (a pump) | foregrip (a barrel, a crane)
//
// A weapon package gives one gun seats of its own with the card's `handprofile = <word>`
// and a set here named wm_hs_<word>_* in ITS CVARINFO; a seat it leaves out falls back
// to the gun's type, then to default.
//
// NOSAVE, NOT USER: 980 cvars. A `user` cvar is userinfo -- sent to every player at a
// netgame's start and on every change. nosave keeps them in this machine's ini only.
// The renderer and the sliders read them all the same.
//
// WHERE EACH STARTED (read from doomxr.ini, never written; and from git):
//   pistol      the pistol seats from before the revolver: this file's defaults since
//               537409f, which are RS_TestPistol's own tuned rs_tp_slide_* / rs_tp_mag_*
//   revolver    slide and mag carry YOUR REVOLVER TUNING from doomxr.ini -- the stopgap
//               revolvers (eabd6bb) worked a role = action hammer and a role = feed
//               speedloader, which read wm_<main|off>_slide and _mag, the pistols' own
//               sets; that is how tuning the revolver moved the pistol. Its foregrip
//               (barrel, crane) is the ini's too: still the shipped default.
//   shotgun     the pistol's, and the pump's shipped estimate (never tuned: the ini
//               still holds its default)
//   breakaction the revolver's foregrip (the shipped default) and the pistol's others
//   the rest    the pistol's, until a gun of that kind is tuned
//
